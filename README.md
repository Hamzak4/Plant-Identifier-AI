A smart gardening companion that combines AI and modern Android development to help users identify plants, diagnose diseases, learn about botany, and manage plant care routines.

✨ Key Features:
• Instant plant identification from photos
• AI-powered disease diagnosis (Plant Doctor)
• Botanical essay generation in English & Urdu
• 24/7 AI Botanist Chat
• Smart watering & fertilizing reminders
• Personalized themes and gardener profiles

🛠️ Built With:
• Kotlin
• Jetpack Compose
• Material Design 3
• Gemini AI
• Retrofit
• Room Database
• Firebase Authentication

This project helped me gain hands-on experience with AI integration, modern Android architecture, local data persistence, and intuitive UI/UX design.
